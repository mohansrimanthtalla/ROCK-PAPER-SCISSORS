# 🎮 Rock Paper Scissors Tournament

A console-based Rock Paper Scissors Tournament developed using Python.

## 📖 Description

This project is an advanced version of the classic Rock Paper Scissors game. The player competes against the computer in a Best-of-5 tournament. The game includes score tracking, match history, statistics, and a user-friendly menu system.

## ✨ Features

- Best-of-5 Tournament Mode
- Score Tracking
- Match History
- Rules Section
- Input Validation
- Final Tournament Result
- Statistics Display
- Menu-Driven Interface
- Random Computer Moves

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/mohansrimanthtalla/ROCK-PAPER-SCISSORS.git
```

2. Navigate to the project folder:

```bash
cd ROCK-PAPER-SCISSORS
```

3. Run the program:

```bash
python rock_paper_scissors.py
```

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- First player to win 3 rounds wins the tournament
